# KeyStack

**KeyStack — приложение для общения с нейросетями в одном месте.** Подключите своего AI-провайдера, выберите модель и ведите переписки с компьютера или Android-устройства.

## Возможности

- **Несколько AI-провайдеров.** Подключение OpenAI, Claude, Google Gemini, Mistral, Groq, DeepSeek, OpenRouter и других совместимых сервисов.
- **Выбор модели.** Используйте модели, доступные вашему аккаунту и API-ключу.
- **Ответы в реальном времени.** Текст появляется по мере генерации.
- **История чатов.** Создавайте отдельные диалоги и возвращайтесь к предыдущим беседам.
- **Настройка подключения.** Для совместимых сервисов можно указать собственный адрес API.
- **Темы оформления.** Доступные варианты оформления зависят от платформы и версии приложения.

## Скачать KeyStack

Все актуальные версии публикуются на [странице релизов](https://github.com/Toska-0/KeyStack/releases).

### Android

1. Откройте [Releases](https://github.com/Toska-0/KeyStack/releases).
2. Выберите последний выпуск и скачайте файл APK.
3. Откройте APK на телефоне и подтвердите установку. Если Android запросит разрешение, разрешите установку приложений из используемого источника.

### Windows x64

1. Откройте [Releases](https://github.com/Toska-0/KeyStack/releases).
2. Скачайте MSI-установщик для Windows x64.
3. Запустите файл MSI и следуйте инструкциям установщика.

Если нужного установочного файла ещё нет в Assets релиза, значит сборка для этой платформы пока не опубликована. Файлы **Source code (zip)** и **Source code (tar.gz)** — это архивы исходного кода, они не предназначены для обычной установки.

## Первый запуск

1. Запустите KeyStack.
2. Выберите AI-провайдера.
3. Введите API-ключ из личного кабинета этого провайдера.
4. Выберите доступную модель и при необходимости укажите адрес API.
5. Сохраните настройки и начните чат.

**Важно:** KeyStack не продаёт доступ к нейросетям и не выдаёт API-ключи. Доступность моделей, лимиты и стоимость запросов определяет выбранный провайдер. API-доступ часто оплачивается отдельно от обычной подписки на сайт или приложение провайдера.

## Рабочая папка на Windows

В Windows-версии в настройках можно выбрать папку на компьютере для работы с файлами.

- Нейросеть может получать содержимое поддерживаемых текстовых файлов из выбранной папки в пределах ограничений приложения.
- По вашему запросу KeyStack может создавать и обновлять файлы в этой папке.
- Перед изменением важных файлов рекомендуется сделать резервную копию и проверять результат.
- Не помещайте в рабочую папку пароли, ключи и другие данные, которые не хотите отправлять AI-провайдеру.

Рабочая папка предназначена для файлов внутри выбранного каталога и не является удалённым управлением всем компьютером.

## API-ключи и конфиденциальность

Для получения ответов приложение отправляет ваши сообщения выбранному AI-провайдеру. Провайдер обрабатывает переданные данные согласно собственным условиям и политике конфиденциальности. Настройки и данные приложения сохраняются локально в соответствии с особенностями платформы.

Не отправляйте в чат пароли, платёжные данные и другую конфиденциальную информацию, если не готовы передавать её выбранному провайдеру.

## Решение проблем

- Проверьте подключение к интернету и правильность API-ключа.
- Убедитесь, что выбранная модель доступна вашему аккаунту и у провайдера не исчерпан лимит.
- Если Windows-версия не может открыть рабочую папку, проверьте, что папка существует и у вашей учётной записи есть права доступа.
- Если проблема сохраняется, создайте обращение в [Issues](https://github.com/Toska-0/KeyStack/issues). Не публикуйте там API-ключи, пароли и личные данные.
