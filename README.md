# KeyStack

**KeyStack — приложение для общения с нейросетями в одном удобном месте.**

Подключите подходящего AI-провайдера, выберите модель и ведите диалог без необходимости пользоваться отдельным сайтом для каждой нейросети.

## Что умеет KeyStack

- **Разные AI-провайдеры.** Подключайте OpenAI, Claude, Google Gemini, Mistral, Groq, DeepSeek, OpenRouter и другие совместимые сервисы.
- **Выбор модели.** Используйте нужную модель своего провайдера. Доступность моделей зависит от вашего аккаунта и API-провайдера.
- **Ответы в реальном времени.** Текст ответа появляется постепенно, по мере генерации.
- **История переписок.** Создавайте отдельные чаты, возвращайтесь к прошлым разговорам, переименовывайте, закрепляйте и удаляйте диалоги.
- **Вложения.** Прикрепляйте изображения и файлы через системное окно выбора файлов.
- **Своя рабочая папка на компьютере.** Укажите папку, с файлами которой нейросеть сможет работать: читать поддерживаемые текстовые файлы и создавать или обновлять файлы по вашему запросу.
- **Оформление.** Выбирайте системную, светлую, тёмную или AMOLED-тему.
- **Свои совместимые сервисы.** При необходимости укажите адрес OpenAI-совместимого API.

## Установка на Windows

1. Откройте [страницу загрузок KeyStack](https://github.com/Toska-0/KeyStack/releases).
2. Скачайте установщик KeyStack для Windows в формате MSI. Если хотите использовать портативную версию без обычной установки, скачайте ZIP-архив.
3. Для MSI запустите скачанный файл и следуйте инструкциям установщика.
4. Для ZIP распакуйте архив в удобное место и запустите KeyStack.exe из распакованной папки.

Если на странице загрузок пока нет готового установщика, значит выпуск ещё не опубликован. Не скачивайте исходный код вместо установщика.

## Первый запуск

1. Откройте KeyStack.
2. Выберите AI-провайдера, которым хотите пользоваться.
3. Введите API-ключ, полученный в личном кабинете выбранного провайдера.
4. Выберите модель и, если требуется, укажите адрес API.
5. Сохраните настройки и начните новый чат.

**Важно:** KeyStack не предоставляет платный доступ к моделям и не выдаёт API-ключи. Условия использования, доступные модели, лимиты и стоимость запросов определяет выбранный провайдер. Обычно API оплачивается отдельно от подписки на сайт или приложение провайдера.

## Рабочая папка

В настройках Windows-версии можно выбрать папку на компьютере, которую вы хотите использовать вместе с нейросетью.

- KeyStack передаёт модели содержимое поддерживаемых текстовых файлов из выбранной папки в пределах установленных ограничений.
- По вашей просьбе модель может подготовить файлы для создания или обновления в этой папке.
- Запись выполняется только внутри выбранной рабочей папки. Не разрешайте модели изменять файлы, если не уверены в результате.
- Изменения файлов на компьютере происходят локально. Перед важными изменениями рекомендуется сделать резервную копию.

Рабочая папка не означает полный удалённый доступ к компьютеру: KeyStack не должен использовать её для доступа к произвольным файлам за её пределами.

## Конфиденциальность и API-ключи

Настройки, API-ключи и история чатов Windows-версии сохраняются локально в папке данных KeyStack в вашем профиле Windows. Для получения ответов приложение отправляет запросы выбранному AI-провайдеру. Поэтому содержимое отправленных сообщений и прикреплённых материалов обрабатывается этим провайдером согласно его правилам и политике конфиденциальности.

Не вставляйте в чаты пароли, платёжные данные и другую конфиденциальную информацию, если не хотите передавать её выбранному провайдеру.

## Если что-то не работает

- Проверьте подключение к интернету и правильность API-ключа.
- Убедитесь, что у вашего аккаунта провайдера есть доступ к выбранной модели и достаточно средств или лимитов.
- Если не открывается рабочая папка, проверьте, что она существует и у вашей учётной записи Windows есть права доступа.
- Если проблема сохраняется, сообщите об ошибке в [разделе Issues](https://github.com/Toska-0/KeyStack/issues). Не прикладывайте API-ключи, пароли или личные данные.
